# Sa.Ni.Ca. — I Creatori del Verde

Versione statica del sito.

## Avvio locale

Con Python 3:

```bash
python serve.py
```

Poi aprire `http://127.0.0.1:8000/`.

La struttura usa collegamenti interni portabili, così il sito può essere servito da GitHub Pages o da un hosting statico senza dipendere dal dominio definitivo.

## Pubblicazione

Prima della pubblicazione definitiva vanno sostituiti nel `sitemap.xml` e in `robots.txt` gli URL provvisori con il dominio reale.

Le pagine Privacy e Cookie richiedono i dati giuridici effettivi del titolare e la verifica della configurazione reale del sito prima della pubblicazione.
